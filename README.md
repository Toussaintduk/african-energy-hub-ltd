# African Energy Hub Ltd - Website

Professional supply, installation, and maintenance of electrical materials and equipment for public institutions, private organizations, and individuals across Rwanda.

## Features

- Modern, responsive design built with React and Tailwind CSS
- Component-based architecture using shadcn/ui
- TypeScript for type safety
- Vite for fast development and builds
- Multiple sections: Hero, About, Services, Team, Impact, and more

## Getting Started

### Prerequisites

- Node.js 18+ or Bun
- npm or Bun package manager

### Installation

```bash
npm install
# or
bun install
```

### Development

```bash
npm run dev
# or
bun dev
```

The app will start at `http://localhost:8080`

### Building

```bash
npm run build
# or
bun run build
```

### Testing

```bash
npm run test
npm run test:watch
```

### Linting

```bash
npm run lint
```

## Project Structure

```
src/
├── components/      # Reusable UI components and page sections
├── pages/          # Page components
├── lib/            # Utility functions
├── assets/         # Images and static files
└── test/           # Test files
```

## Tech Stack

- **React 18** - UI library
- **TypeScript** - Type safety
- **Vite** - Build tool and dev server
- **Tailwind CSS** - Utility-first CSS framework
- **shadcn/ui** - High-quality React components
- **React Router** - Client-side routing
- **React Query** - Data fetching and caching
- **Recharts** - Data visualization
- **Zod** - Schema validation
- **Vitest** - Unit testing
